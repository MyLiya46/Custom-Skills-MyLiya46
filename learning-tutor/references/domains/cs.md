# 计算机领域教学手册（cs.md）

> 覆盖示例主题：MCP 系统学习、C++ 快速上手、Python 入门（共 3 个）。
> 教学路径中的每课容量均为默认 25 分钟可消化量，用户可协商调整。

## 一、教学总则

1. 内容来源：技术类教学内容先联网查阅官方技术文档（MCP：modelcontextprotocol.io/specification；C++：ISO/IEC 14882 标准与 cppreference.com；Python：docs.python.org），确定内容结构、术语与当前最佳实践，再重组为教学语言。
2. 禁止整段搬运官方文档原文；重组时保留术语准确性，用自己的语言组织。
3. 教学顺序：先概念后实操；每课含至少 1 个动手练习。
4. 每个概念给出 1 个实际应用场景，先讲"为什么存在"再讲细节。
5. 联网查阅失败或网络不可用：基于现有知识教学，并在该课开头告知"本节未参考最新官方文档"。
6. 英文术语首次出现时给出中文释义（如 tool=工具，模型可调用的能力）。
7. 环境前置：教学前确认用户运行环境（编译器 / Node / Python 等）；环境未就绪先教环境搭建，不开始正课。
8. 报错处理：按"报错原文 → 原因 → 修复步骤"三步回复。

## 二、示例主题 1：MCP 系统学习

### 2.1 教学要点

- 定位：MCP（Model Context Protocol，模型上下文协议）是连接 AI 应用与外部工具、数据源的开放协议，类比"AI 应用的 USB-C 接口"。
- 知识图谱位置：AI 应用开发 → 工具调用 / Agent → 协议层（MCP）。
- 最新规范：2026-07-28 版本（modelcontextprotocol.io/specification/2026-07-28）；教学前联网确认最新版本号与内容。
- 核心概念（与最新规范一致）：
  - 三方角色：host（宿主，用户所在应用）/ client（客户端）/ server（服务器，提供能力与数据）。
  - 三大原语：tools（工具，模型控制的可执行函数；tools 是任意代码执行，须谨慎授权）/ resources（资源，应用控制的上下文数据）/ prompts（提示词模板，用户触发）。
  - 传输：stdio 与 Streamable HTTP。
  - 消息：JSON-RPC 2.0；最新规范为无状态协议，请求携带协议版本与能力信息，不再有初始化握手。
  - 能力协商：server 通过 server/discover 宣告支持的版本、能力与身份。
  - MRTR（多轮请求）：服务器需要补充信息时返回 resultType 为 input_required 的结果，而非发起新请求。
- 版本差异：存量生态仍运行 2025-11-25 及更早版本（含 initialize 握手、session 头），教学时一句话带过版本差异，不展开旧细节。
- 授权：授权机制（OAuth 2.1 等）以官方规范为准。
- 零基础入口：先回答"没有 MCP 之前 AI 应用如何对接工具"——每个应用各写集成代码、重复造轮子；MCP 统一了这一过程。

### 2.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | MCP 是什么：在 AI 应用全景中的位置；USB-C 类比；解决的问题 | 复述要点：用一句话向小白解释 MCP 并举 1 个实际场景 |
| 2 | 三方角色 host / client / server 与一次工具调用链路 | 动手练习：复述一次调用链路，标注每一步的角色 |
| 3 | 三大原语 tools / resources / prompts：定义、控制方、适用场景 | 动手练习：为同一场景各举 1 个例子 |
| 4 | 传输与消息：stdio / Streamable HTTP、JSON-RPC 2.0、无状态协议与 server/discover | 动手练习：画出 / 描述一次能力发现与调用的消息流程 |
| 5 | 动手实操：按官方 quickstart 用 SDK 运行最小 server 并连接 | 动手练习：提交运行结果与你的理解；网络不可用时改为设计该 server 的 tools 清单 |
| 6 | 授权与安全：授权流程、tools 任意代码执行风险、最小权限原则 | 场景迁移：指出 1 个实际安全隐患场景并说明防护 |
| 7 | 生态与进阶（选学）：MRTR、订阅变更、官方扩展（tasks 等）、规划自己的 server | 场景迁移：规划 1 个自己的 MCP server 方案 |

### 2.3 零基础入口 / 常见卡点与替代讲法

- 零基础入口：从"AI 为什么需要协议"讲起；诊断时询问是否了解 HTTP/JSON，不了解则第 1 课补 5 分钟术语说明。
- 分不清 client 与 server → "点菜与后厨"类比：client 提需求（点菜），server 出能力（上菜）。
- 觉得协议抽象 → "插座标准"类比：不同家电（AI 应用）通过统一插座（协议）接上电。
- 规范版本多 → 只教最新版结构，旧版本差异一句话带过。
- 环境安装失败 → 逐条处理报错，按"报错原文 → 原因 → 修复步骤"给出步骤，不跳过任何一行。

## 三、示例主题 2：C++ 快速上手

### 3.1 教学要点

- 定位：C++ 是通用高性能系统级语言；"快速上手"以能写、能编译、能运行为目标。
- 知识图谱位置：编程语言 → 编译型语言 → C++；与 C、Python 对照理解。
- 标准现状（2026 年核实）：C++23 为当前已发布标准（ISO/IEC 14882:2024）；C++26 于 2026 年 3 月完成发布（合约 contracts、反射 reflection、std::execution 等）。入门教学使用 C++17/20 常用特性，C++23/26 特性作介绍，以编译器实际支持为准。
- 核心概念：编译执行流程（源码 → 编译器 → 可执行文件）、变量与类型、控制流、函数、类与对象、引用与传参、栈与堆、智能指针（unique_ptr / shared_ptr）、STL 容器与算法（vector / string / map / sort）。
- 官方来源：ISO/IEC 14882 标准；cppreference.com；编译器 GCC / Clang / MSVC。
- 零基础入口：从"Hello World 从源码到运行的完整过程"建立编译执行心智模型。

### 3.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 工具链与第一个程序：安装编译器、编译运行 Hello World、读编译报错 | 动手练习：提交运行结果 + 一句话解释"编译" |
| 2 | 变量、类型与输入输出（cin / cout） | 动手练习：写一个摄氏 / 华氏温度转换程序 |
| 3 | 控制流与函数：if / for / while、函数定义与调用 | 动手练习：猜数字小游戏 |
| 4 | 数组、string 与 vector | 动手练习：统计一段文本的单词数并输出前 3 个最长单词 |
| 5 | 传值、传引用与 const | 动手练习：写 swap 函数并解释三种方式的差异 |
| 6 | 类与对象：封装、构造函数、成员函数 | 动手练习：设计"学生"类（属性 + 2 个方法） |
| 7 | 内存基础：栈 / 堆 / 指针 / 智能指针（RAII 概念） | 动手练习：描述一个内存泄漏场景并给出修复写法 |
| 8 | STL 容器与算法：map / sort / find | 动手练习：用 map 统计词频并排序输出 |
| 9 | 综合项目：通讯录管理（增删查改） | 教给他人 + 动手练习：提交完整代码并讲解设计选择 |

### 3.3 零基础入口 / 常见卡点与替代讲法

- 零基础入口：先讲"源代码 → 编译器 → 可执行文件"三步；学过其他语言则每课开头做对照（Python 的 list ≈ C++ 的 vector）。
- 编译报错恐惧 → 规则：报错第一行是定位，最后一行是原因；先教读错再教改错。
- 指针难懂 → 入门只教引用与值传参，指针放第 7 课；用"快递柜"类比指针（存的是地址，不是物品）。
- 漏分号 / 括号不配对 → 安排 1 个专门练习：修复 5 个故意写错的小程序并逐条说明报错含义。

## 四、示例主题 3：Python 入门（补充）

### 4.1 教学要点

- 定位：解释型通用语言，适合脚本、数据分析与 AI 应用开发。
- 核心概念：解释执行、动态类型、列表与字典、函数、模块、异常处理。
- 官方来源：docs.python.org。
- 零基础入口：在交互式环境 REPL 中直接体验语句执行。

### 4.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 环境与 REPL：安装、交互式运行、变量与 print | 动手练习：提交 3 条你尝试过的语句与结果 |
| 2 | 列表、字典与循环 | 动手练习：统计一段文字的词频 |
| 3 | 函数与模块：定义、参数、import | 动手练习：把词频统计封装为函数并导入使用 |
| 4 | 文件读写与异常处理 | 动手练习：读取文件并处理文件缺失的错误 |
| 5 | 小项目：命令行记账本（收支记录 + 汇总） | 动手练习：提交代码与运行演示 |
