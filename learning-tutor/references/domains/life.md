# 生活领域教学手册（life.md）

> 覆盖示例主题：厨艺入门（做饭）、新手健身（锻炼）、跑步入门（共 3 个）。
> 教学路径中的每课容量均为默认 25 分钟可消化量，用户可协商调整。

## 一、教学总则

1. 实操为主：每个操作给出可测量的信号（如"油温六成热 = 油面出现细纹"），不用模糊描述。
2. 安全前置：每课开头列出本课安全提示（明火 / 刀具 / 油温 / 器械动作），用 ⚠️ 标注；每次实操前重申 1 条对应提示。
3. 替代方案：列出常见设备与食材替代（没有烤箱用平底锅；没有哑铃用装满水的矿泉水瓶；缺指定食材提供 2 个等价替代菜）。
4. 反馈看过程：批改时请用户描述动作过程（温度、颜色、手感、时间、组数），按描述纠正。
5. 一课一成果：做饭课每课出一盘菜；健身课每课交付一组标准动作。
6. 医疗边界：本 Skill 不提供医疗建议；有伤病史、心血管疾病史者先咨询医生；动作中出现尖锐疼痛立即停止。

## 二、示例主题 1：厨艺入门（做饭）

### 2.1 教学要点

- 知识图谱位置：生活技能 → 烹饪 → 备菜 / 烹调 / 调味 / 营养。
- 核心能力：厨房安全、火候与油温判断、基本刀工、调味逻辑（咸 / 甜 / 酸 / 鲜）、熟成判断、营养搭配（主食 + 蛋白质 + 蔬菜）。
- 学习主线：安全与备菜 → 火候油温 → 调味 → 基本功菜 → 独立搭配一餐。
- 零基础入口：第 1 课只学安全与备菜，不碰明火；第 2 课才开火。

### 2.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 备菜与安全：刀具握法、切法（条 / 片 / 丁）、切伤与烫伤处理 | 动手练习：完成土豆切条，描述切法与手感 |
| 2 | 第一道菜：番茄炒蛋（备料、蛋液处理、油温判断、下锅顺序） | 动手练习：按步骤做一次，提交成品描述与遇到的问题 |
| 3 | 煮与焯：煮面、煮蛋、焯青菜（水量、火候、时间表） | 动手练习：做出 3 种蛋熟度中的 1 种，记录时间 |
| 4 | 炒菜基本功：蒜蓉炒青菜（热锅凉油、大火快炒、调味时机） | 动手练习：完成并描述调味时机选择的原因 |
| 5 | 调味逻辑：盐、糖、生抽、醋的作用与起始比例 | 动手练习：为一道菜设计调味方案并试做，记录用量 |
| 6 | 综合：独立设计并完成一顿两菜一汤，讲清营养构成 | 教给他人：把流程讲给家人或朋友并记录对方的问题 |

### 2.3 常见卡点与替代讲法

- 油温难判断 → 改用可测量信号：筷子插入油中冒细泡 = 五六成热。
- 咸淡拿不准 → 规则：宁淡勿咸，尝一口再决定是否加盐。
- 缺指定食材 → 每课提供 2 个等价替代菜（如青椒肉丝 → 蒜苔肉丝）。

### 2.4 安全提示清单（每课必带）

- ⚠️ 明火操作不离人；热油中不加水。
- ⚠️ 切菜时手指内扣呈猫爪状，刀不离板。
- ⚠️ 烫伤先冲冷水 15 分钟，不涂牙膏酱油。

## 三、示例主题 2：新手健身（锻炼）

### 3.1 教学要点

- 知识图谱位置：健康 → 运动 → 力量训练 / 有氧 / 恢复。
- 核心能力：动作标准、组次安排（如 3 组 × 8-12 次）、热身与拉伸、循序增量规则（每周每动作微增）、安全边界（不硬撑）。
- 学习主线：热身与体测 → 徒手动作标准 → 组次与休息 → 全身计划 → 增量规则 → 周期回顾。
- 零基础入口：从体测与热身开始；所有动作提供退阶版本（墙推俯卧撑、箱式深蹲）。

### 3.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 体测与热身：记录基线（可做的深蹲 / 俯卧撑个数），完成 5-10 分钟动态热身 | 动手练习：执行 1 次热身，提交文字记录 |
| 2 | 深蹲与臀桥标准：站距、下蹲深度、膝盖方向、常见错误 | 动手练习：3 组 × 8-12 次，描述每组感觉 |
| 3 | 俯卧撑与退阶：墙推 → 膝撑 → 标准俯卧撑 | 动手练习：选退阶版本做 3 组并记录次数 |
| 4 | 平板支撑与核心：标准姿势、时长、退阶 | 动手练习：3 次 × 30 秒，记录姿势与抖动情况 |
| 5 | 编排全身计划：热身 + 3 动作 + 拉伸，组间休息 60-90 秒 | 动手练习：执行 1 个完整计划并记录数据 |
| 6 | 渐进增量与周期回顾：每周加量边界，复盘基线变化 | 复述要点 + 场景迁移：制定你的首周训练表 |

### 3.3 常见卡点与替代讲法

- 动作变形 → 每课给 1 个动作自检口诀（深蹲：膝盖朝脚尖方向，腰背挺直）。
- 次日酸痛 → 解释延迟性肌肉酸痛（DOMS），安排低强度活动日，不因酸痛停课。
- 不硬撑规则 → 每课提示：动作走形即停，宁可少做也要保持标准。

### 3.4 安全提示清单（每课必带）

- ⚠️ 运动前必做热身，运动后必做拉伸。
- ⚠️ 有心血管疾病史者先咨询医生再开始训练。
- ⚠️ 动作中出现尖锐疼痛立即停止，不硬撑。

## 四、示例主题 3：跑步入门（补充）

### 4.1 教学要点

- 知识图谱位置：健康 → 运动 → 有氧耐力 → 跑步。
- 核心概念：跑前动态热身、慢跑配速（能交谈为准）、跑姿要点（小步幅、快步频、核心稳定）、跑量递增不超过 10% / 周、跑后拉伸与休息日。
- 安全提示：膝盖或脚踝疼痛立即停止，咨询医生；不提供医疗建议。
- 零基础入口：从"走跑结合"起步，第 1 次训练以 10 分钟慢跑 + 走为目标。

### 4.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 跑前准备与第一次慢跑：跑鞋选择、动态热身、10 分钟慢跑 + 走 | 动手练习：完成 1 次并记录配速与体感 |
| 2 | 跑姿与呼吸：小步幅快步频、核心稳定、两步一吸两步一呼 | 动手练习：跑后对照要点自评 3 条 |
| 3 | 跑量进阶与计划：每周 3 次、递增不超过 10%、走跑结合 | 场景迁移：制定你的 4 周训练计划表 |
| 4 | 恢复与常见伤病预防：休息日、拉伸、胫骨疼与膝痛的处理原则 | 复述要点：列出 3 个"该停跑"的信号 |
