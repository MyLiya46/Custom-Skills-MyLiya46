# 金融领域教学手册（finance.md）

> 覆盖示例主题：理财基础入门、股票入门、基金入门、财报阅读入门（共 4 个）。
> 教学路径中的每课容量均为默认 25 分钟可消化量，用户可协商调整。
> 本手册内容为教学，不构成投资建议。

## 一、教学总则

1. 内容来源：基于公认权威来源组织教学——中国证监会投资者教育基地、中国人民银行金融知识专栏、沪深交易所与基金业协会官方投资者教育材料、正规理财教材体系。
2. 数据与费率等时效性内容标注"以官方最新发布为准"。
3. 不推荐任何具体产品，只教概念、原理与方法；不用"稳赚""保本""无风险"等表述，不承诺任何收益。
4. 风险前置：每课开头用 1 分钟说明本课内容的常见风险与适用边界。
5. 数字先行：涉及利率、费用、收益率时，先给具体数字例子，再给公式；举例用生活化金额。
6. 收尾串联：每个主题最后一课安排"场景迁移"或"教给他人"输出任务。

## 二、示例主题 1：理财基础入门

### 2.1 教学要点

- 知识图谱位置：个人财务 → 理财规划 → 储蓄 / 保险 / 投资。
- 核心概念：结余（收入 - 支出）、记账与预算、应急金（3-6 个月开支）、复利与 72 法则、通胀对购买力的影响、风险与收益匹配、保险基础（医疗 / 重疾 / 意外）。
- 学习主线：收支盘点 → 应急金 → 复利原理 → 风险认知 → 配置框架。
- 零基础入口：从"为什么理财"讲起——记账 1 周看清现金流，再谈储蓄目标；术语首次出现给一句话定义（如"结余=每月剩下可用的钱"）。

### 2.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 理财第一步：盘点收支，结余 = 收入 - 支出 | 动手练习：列出你 3 天的收支分类表 |
| 2 | 应急金：为什么先备 3-6 个月开支；存放工具 | 动手练习：计算你的应急金目标金额与筹集计划 |
| 3 | 复利、通胀与 72 法则：用具体数字演示 | 动手练习：用 72 法则计算一笔存款翻倍年数并解释用法 |
| 4 | 风险与收益匹配：为什么高收益伴随高波动 | 类比解释：为"波动"造一个生活化类比 |
| 5 | 保险入门与配置框架：保障顺序（先保障后理财）与资产粗分 | 场景迁移：列出你家庭的风险点与应对 |

### 2.3 常见卡点与替代讲法

- 复利抽象 → 用计算表演示：10000 元、年化 5%，逐年列出 10 年金额。
- 风险讲不清 → 用一句话替代："收益是波动的奖励，波动就是风险"。

## 三、示例主题 2：股票入门

### 3.1 教学要点

- 知识图谱位置：投资 → 权益类资产 → 股票。
- 核心概念：股票（公司所有权份额与股东权利）、发行与上市、交易市场与规则（上交所 / 深交所 / 北交所、开户流程、T+1、1 手 = 100 股、涨跌幅限制）、指数（上证指数 / 沪深 300）、估值指标（市盈率 PE / 市净率 PB / 股息率）、股价决定因素（基本面与情绪面）、风险与纪律。
- 学习主线：股票是什么 → 交易机制 → 股价从哪来 → 风险纪律。
- 零基础入口：从"买股票 = 成为公司小股东"起步，第 1 课不碰交易机制。

### 3.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 股票是什么：所有权、分红、股东权利；与存款 / 债券对照 | 复述要点：向小白解释"买股票 = 当老板的一小部分" |
| 2 | 市场与交易规则：交易所、T+1、1 手 = 100 股、涨跌幅限制 | 复述要点：描述一次完整买入流程并标注规则限制 |
| 3 | 指数与市场观测：上证指数 / 沪深 300 / 行业指数 | 类比解释：解释"今天大盘涨了"这句话的含义 |
| 4 | 估值指标：PE / PB / 股息率的定义与计算示例 | 动手练习：为 2 组模拟数据计算并比较 PE |
| 5 | 股价决定：基本面、消息面、情绪面 | 场景迁移：为一个新闻事件推演对相关公司的影响 |
| 6 | 风险与纪律：波动、亏损、不借钱炒股、止损与仓位概念 | 场景迁移：写出你自己的 3 条交易纪律 |

### 3.3 常见卡点与替代讲法

- 股价逻辑混乱 → 拆成两句话："长期看基本面，短期看情绪"。
- 想快速赚 → 第 6 课用数字演示频繁交易的手续费如何吞噬收益。

## 四、示例主题 3：基金入门

### 4.1 教学要点

- 知识图谱位置：投资 → 集合投资 → 公募基金。
- 核心概念：基金（集合投资、专业管理）、基金类型（货币 / 债券 / 混合 / 股票 / 指数 / QDII）、净值、申购与赎回、费率（申购费 / 赎回费 / 管理费 / 托管费）、定投机制与适用场景、风险等级（R1-R5）与风险测评。
- 学习主线：基金是什么 → 净值与交易 → 费用 → 类型选择 → 定投 → 配置方案。
- 零基础入口：用"大家凑钱、请专业人士打理"类比集合投资；不预设任何交易经验。

### 4.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 基金是什么：集合投资与专业管理；与直接买股票的区别 | 复述要点：用一句话解释基金与直接买股票的区别 |
| 2 | 净值、申购与赎回：用数字例子走一遍流程 | 动手练习：计算一笔申购的份额、市值与实际成本 |
| 3 | 费用：申购费、赎回费、管理费、托管费怎么扣 | 动手练习：计算 10 万元、年管理费 1.5% 一年扣多少 |
| 4 | 基金类型：货币 / 债券 / 混合 / 股票 / 指数 / QDII 的用途 | 场景迁移：为 3 个生活场景各选一类基金并说明理由 |
| 5 | 定投：机制、微笑曲线、适用与不适用场景 | 动手练习：画出 / 描述定投在下跌与上涨中的效果差异 |
| 6 | 风险等级与配置：R1-R5 等级、风险测评、分散配置示例 | 场景迁移：为一个模拟风险测评结果设计配置方案 |

### 4.3 常见卡点与替代讲法

- 净值涨跌看不懂 → 用"包子店价格"类比：净值是基金资产的价格，涨跌反映持仓资产价值。
- 忽略费用 → 每课的费用计算落到具体金额，并对比"收费高的长期差异"。

## 五、示例主题 4：财报阅读入门

### 5.1 教学要点

- 知识图谱位置：投资分析 → 基本面分析 → 财务报表。
- 核心概念：三张报表的分工（资产负债表 = 家底、利润表 = 赚多少、现金流量表 = 收到多少钱）、关键科目与指标（营收、净利润、毛利率、负债率、经营现金流）、三表勾稽关系。
- 学习主线：三张表各管什么 → 逐表读法 → 关键指标 → 综合解读一家公司。
- 零基础入口：用生活类比入门——资产负债表 = 体检表，利润表 = 成绩单，现金流量表 = 日常账本。

### 5.2 教学路径（每课默认 25 分钟）

| 课号 | 主题 | 输出任务 |
| --- | --- | --- |
| 1 | 三张报表总览：各管什么、如何配合 | 复述要点：用一句话说清一张表的分工 |
| 2 | 利润表：营收、成本、净利润的勾稽关系 | 动手练习：补全一张简化利润表并计算毛利率 |
| 3 | 资产负债表：资产 = 负债 + 所有者权益 | 动手练习：补全等式练习并解释 2 个关键科目 |
| 4 | 现金流量表与三表联动："利润高但缺现金"的情形 | 类比解释：解释一个"账面赚钱却缺现金"的场景 |

### 5.3 常见卡点与替代讲法

- 三张表关系乱 → 用"一个包子铺"的经营数字把三张表串讲一遍，再回到抽象概念。
